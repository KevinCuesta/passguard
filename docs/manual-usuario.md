# Manual de usuario — versión inicial

1. Abre PassGuard en el navegador.
2. En **Evalúa una contraseña**, ingresa solo una contraseña de prueba. El análisis se actualiza localmente mientras escribes. Usa el botón del ojo para mostrar u ocultar el texto.
3. Lee el nivel, la longitud, los patrones detectados y las sugerencias. La puntuación es orientativa.
4. En **Generación**, ajusta la longitud y selecciona el alfabeto. Pulsa **Generar contraseña**.
5. Usa **Copiar** solo si quieres copiar la contraseña al portapapeles. Trata el portapapeles como información sensible.

La página no persiste la contraseña de evaluación. Al cerrar o recargar la pestaña se pierde. El mejorador y la consulta de filtraciones todavía no están incluidos en esta versión.
