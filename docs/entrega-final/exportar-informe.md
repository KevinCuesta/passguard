# Exportar el informe a PDF o Word

El entorno de preparación no tiene Pandoc, LibreOffice ni Microsoft Word disponibles como herramientas de conversión, y no se añadió ninguna dependencia al proyecto. La fuente académica se conserva en Markdown editable: [informe-academico.md](../proyecto-de-aula/informe-academico.md).

## PDF sin instalar dependencias

1. Después de publicar el repositorio, abrir el archivo Markdown en la vista renderizada de GitHub; también puede abrirse el preview de Markdown del editor.
2. Usar **Imprimir → Guardar como PDF** en el navegador.
3. Seleccionar papel A4, márgenes adecuados y escala legible.
4. Revisar el PDF página por página: portada, encabezados, tablas, enlaces, saltos y que no haya texto recortado.
5. Si la institución exige portada/encabezado o estilo específico, adaptar primero la fuente Markdown a la plantilla.

## Word / DOCX

1. Abrir Word y crear un documento basado en la plantilla institucional.
2. Copiar el contenido renderizado del Markdown y pegarlo en el documento.
3. Aplicar los estilos de Word **Título**, **Encabezado 1**, **Encabezado 2** y estilos de tabla/lista; configurar sangría francesa en las referencias si la rúbrica lo exige.
4. Insertar numeración de páginas y revisar tablas/ecuaciones en vista de impresión.
5. Guardar una copia `.docx` y conservar intacto el Markdown como fuente del proyecto.

No se generó ni adjuntó un PDF/DOCX porque no se contó con conversor disponible ni con la plantilla institucional, que sigue pendiente de confirmación.
